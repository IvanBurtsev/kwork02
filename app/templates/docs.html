📖 Документация API

Единый эндпоинт для работы с DeepSeek и OpenAI через ваш API-ключ.

🔗 Базовый URL
http://127.0.0.1:8000/v1/chat/completions
📦 Формат запроса (JSON)
{
  "model": "deepseek-chat",
  "messages": [
    {"role": "user", "content": "Hello!"}
  ],
  "temperature": 0.7,
  "max_tokens": 4096
}
🔐 Аутентификация

Добавьте заголовок:

Authorization: Bearer sk-ваш-ключ

Ключ создаётся в панели управления.

🧪 Тестовый запрос (curl)
curl -X POST http://127.0.0.1:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer sk-ваш-ключ" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"Привет!"}]}'
🔄 Совместимость
Совместим с OpenAI SDK, LangChain, LlamaIndex.
